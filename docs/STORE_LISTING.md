# Store listing description

The text below is what goes in the "description" field when submitting or
updating the listing on Firefox Add-ons (AMO), the Chrome Web Store, and Edge
Add-ons. Copy everything between the `---` markers as-is.

Firefox AMO renders this Markdown properly (bold text, bullet lists, and links
all show up formatted, not as raw symbols). Chrome Web Store and Edge Add-ons
may not — if either shows the `**`/`-`/`[text](url)` syntax literally instead of
rendering it, drop the bold markers and swap each `[label](url)` for the bare
URL on a line under its label; both stores auto-link plain URLs on their own.

Update this file whenever the feature list or links below change, so the next
store submission stays in sync.

animepahe Enhancer makes watching anime on animepahe nicer.

**Features**

- **Continue Watching** — resume exactly where you left off
- **DUB Detector** — see which episodes have English dubs
- **Smart Search** — find shows by romaji, English, or alternate titles
- **Intro / Outro Skip** — skip automatically or with one click
- **Binge Watch** — auto-play the next episode, with a short cancel window
- **Skip Wait** — skip the pahe.win countdown and go straight to kwik
- **Browse** — filter by genre, theme, demographic, type, status, and season

Every feature can be toggled individually.

**Privacy**
No account, analytics, or telemetry. Watch history and settings stay on your device. Smart Search and Intro/Outro Skip send search terms or anime titles/IDs to public services when enabled; both can be turned off in the popup. See the [Privacy policy](https://github.com/abdullahkhfb/animepahe-enhancer/blob/main/PRIVACY.md).
